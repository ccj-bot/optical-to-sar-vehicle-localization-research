# GM MorphologyObject v2：可回指原场的结构对象与冻结宽孔径试探

2026-09-14；分支 `feature/oty2-sar-vehicle-morphology-object`。探索性结果，不是检测器、车辆评分或能力闭环。

## 结论先行

可以把清楚 GT 案例里的部分组织写成**可检查、可反驳的结构记录**：原场、核、候选段、二维关系、合并路径、暗区见证及不确定性均可互相回指。A059 和 GM19 A441 的“主侧/对侧 + 暗间隔”最容易这样阅读。但目前不能把这份记录称作已正确解析的整车对象，更不能据此自动决定哪些单元属于同一辆车。

本轮最有价值的新发现反而是两个失败：

- **干预摧毁形态后，程序仍会生成看似合理的关系。** 只保留强核会产生覆盖暗底板的伪段；填暗内部会产生矩形平台段；像素打乱后仍有 `opposite / serial` 假设。这不是干预失败，而是说明“给候选几何加语义名字”还不等于表达了真实组织。
- **冻结宽窗口里的真实条带仍可见，但未重新形成对应候选段和对象。** 没有扩大窗口、提高预算、评分或选择目标。结果为 `MORPHOLOGY_NOT_RECOVERED_AT_OBJECT_LAYER`，不是“车辆 SAR 信息消失”。

优先打开 [可交互案例目录](../output/morphology_object_v2/INDEX.html)。每页左侧固定 I0；右侧可逐个选择核、段、关系、暗区，查看真实支持像素、原场/平滑场鞍路径和 JSON。浏览器交互验证覆盖全部 20 页。

没有本地完整输出时，可先看 [已提交的小型示例包](../tasks/morphology_object_v2/examples/README.md)：约2.6 MB，包含 A059 原图和同源打乱反例的完整结构/场数据，以及干预和宽窗口说明图。不依赖原始数据目录，也不把局部示例当成全量结果。

## 1. 资产、边界与实际实验量

读取并复用上一轮 [GM morphology object 报告](sar_vehicle_morphology_object_exploration.md)、其 `common.py / topology.py` 及真实图像；输入是 `output/gm_gt_morphology_20260913` 中已有 442 样本索引及选中案例的场文件。只处理 7 个既有观察案例，不重建全部 atlas，不重跑 RSA/G2/R2B 或 PERSON。

| GT 条件案例 | 使用理由 | 本轮观察范围 |
|---|---|---|
| GM17 A059 / f344 g151 | PV002，强主带与弱对侧清楚 | 对象、A–E 干预、冻结宽孔径 |
| GM17 A021 / f330 g115 | PV002 另一帧，单端增强 | 对象 |
| GM17 A085 / f353 g177 | PV002，端团与对侧短片段 | 对象 |
| GM17 A162 / f378 g254 | PV002，碎片组织 | 对象；段层失败 |
| GM11 A312 / f256 g77 | 多层短带 | 对象；上半部漏表达 |
| GM19 A441 / f350 g332 | 对侧组合与暗内部 | 对象、A–E 干预 |
| GM17 A060 / f344 g152 | 既有 M5 不清案例 | 对象；不强迫解释 |

实际保存 7 个 GT 对象、2 个干预原图副本、10 个重建干预对象、1 个宽窗口记录，共 20 份对象记录。它们不是 20 个独立样本。PV002 身份沿用历史标注，既不由结构图推断，也不进入核心函数。

必须区分三层输入：

- `I0`：**上一轮旋转 GT chart 的 `field_bilinear` 原样保留**，不是再次平滑后的场，也不是 native 像素或传感器幅度。7 个数组逐像素相等，源 NPZ 与上一轮 `CASE_LINEAGE.json` 的历史 SHA256 一致。
- 源 NPZ 同时保留 `raw_nearest`、`map_x/map_y`、`imaging_valid`、原 GT geometry；对象的 provenance 指回这些字段，检查器另有 native/context 图链接。7 个已选 aperture 成像有效；没有补洞。
- `I1/I2/I4`：同源高斯分析场，反射边界；只提议结构，不覆盖 I0。宽窗口单独使用 native 灰度 PNG 的原生像素，不旋转、不重采样。因此 GT-release 也包含采样坐标/边界条件差异，不能把全部变化唯一归因于去 GT。

GT 是车辆几何范围，不是响应 Mask。所有图中“上/下/左/右”是该 chart 的坐标，不是物理车头/车尾。尤其 A059 heading 接近 178°，不能把它与 heading 接近 0° 的其他帧直接比较上下侧，解释成目标运动或姿态翻转。光学可见性仅保存为元数据，本轮不据此作可见等级结论。

## 2. 最小对象究竟保存了什么

核心入口 `build_object(z, object_id)` 只接受二维场及不参与计算的记录名；GT/身份元数据在外层附加。`MorphologyObject` 是 **aperture-scoped hypothesis record**：名称不是“框内一切属于一个目标”的声明。

| 组成 | 可回到原场检查的内容 | 当前不承担的责任 |
|---|---|---|
| `full_field` | I0、I1/I2/I4、源文件/采样映射引用、完整多水平树与像素激活节点 | 不把显示灰度称为幅度/RCS |
| `nuclei` | σ=1/2/4 的局部极大值坐标、尺度、I0 取值、邻域原场峰及偏移 | 不叫物理散射中心；跨尺度重复不去重为物体部件 |
| `segments` | 候选支持像素、所含 nuclei、主轴弦、原场弦剖面和两侧剖面 | 弦不是中心线真值；尚无可靠曲段或 serial-fragment 组装 |
| `relations` | `roughly_parallel / along_axis / serial / opposite / separated_by_dark_gap / joins_at_lower_level / weakly_connected_at_lower_level / open_configuration` 等类型及两个端点；I0/I2 各自的精确鞍路径 | 是 `computational_relation_hypothesis`，不是共同归属或车辆结构事实 |
| `dark_open_regions` | 两组峰锚点间横截面、谷种子、两种局部灰度水平的子水平区域、触及哪些 aperture 边界 | 不称车内 Mask；边界开放不等于物理开放周边 |
| `uncertainty` | unresolved grouping、uncertain segment、boundary censored、ambiguous bridge、原场同水平不支持平滑路径、预算停止 | 不为凑出完整 graph 强迫解析 |

主轴来自支持像素 PCA，线是沿轴 5%–95% 投影的**直弦**，并非上一轮 Hessian 脊线。多水平树保留完整节点；静态树图只投影 8 个叶子并编号回指图像，属于阅读裁剪，不进入对象计算或目标选择。旧树内部 elder-rule 的 `winner` 字段在新 JSON 重命名为 `elder_representative`；它仅为持久性记账，不是车辆 winner。

### 提议约定必须公开，不能伪装成“自然车结构”

本轮用 I2 的 q80/q65 连通支持**提出**候选段，支持至少 20 像素、轴向延展至少 12 px、PCA 长宽比至少 2。这里只试验了一种非常初步的中尺度提议方法，不意味着已摆脱 connected-component 的限制。小块和非延展块进入 `proposal_ledger`，不被当作不存在。

关系只在同水平、100 px 内每段至多 3 个近邻对之间提出；25° 是平行/串列的描述容差，60° 是“位移相对两段轴向偏横向”的提议约定。它们限定解析实验，不定义车，也没有形成统一 car score。近邻截断是显式的局部图构建限制，**不是完备关系枚举**，更不是对车辆候选择优。

暗区种子取横截面中间 20%–80% 的低值处，再以“谷值至较弱端点灰度”的 0.2/0.5 水平观察子水平连通区域。它依赖端点、种子和 aperture，不能因为易计算就命名为“暗内部”。距离、角度、鞍值、峰强、尺度、区域面积仅随各自节点/边/区域保存；无 patch feature vector。

## 3. 真实案例：能表达什么，在哪里失真

### A059：成功的是组间组织，失败的是把组画成连续直段

![A059 对象](../output/morphology_object_v2/figures/GM_RM017_f0344_g151_object.png)

顶部主带有多个亮核和延展峰肩；底部不是一个弱 blob，而是若干短横片段。S80_1 和 S65_1 在不同水平表示同一主侧支持的嵌套；S65_2 表示较低水平加入的弱对侧候选组。R1_2 的二维端点能解释“主侧与对侧隔着一片暗区域”，而不仅是“两个分支在某水平合并”。

![A059 原场见证](../output/morphology_object_v2/figures/GM_RM017_f0344_g151_object_witness.png)

必须同时看到不成立的部分：S65_2 的弦跨过暗断口，若干位置甚至低于两侧取样，不能叫连续 ridge。主带的 q65 弦也会切过肩部，而非始终沿最亮中心。**可支持的是有延展方向的多片段组，不是每一条拟合直线。**

R1_2 的 I0 合并鞍值为 57.53125，I2 为 58.84359；I2 路径沿线在 I0 的最低值只有 46.34180。于是“平滑场的这条桥在 58.84 连通”不能直接转述为“原场同位置同水平存在桥”。但 I0 自己在 57.53 仍有另一条连通路径，图中橙/青路径分别展示。路径是 8 邻域最大瓶颈水平上的一条见证，不是唯一桥、不是可见 ridge、更不证明物理归属。

暗谷横截面清楚，但暗区边界不稳定：I0 的 fraction=0.2 区域已有 5,184 像素并触四边；fraction=0.5 膨胀至 10,338 / 11,840 像素。I2 的低水平对应区域为 1,926 像素，仅触左/下边。**横向低谷可解释，封闭/开放区域范围不能据此稳定恢复。**

### GM19 A441：对侧和同侧串列能同时保存

![GM19 对象](../output/morphology_object_v2/figures/GM_RM019_f0350_g332_object.png)

上方多层组与下方右侧短带有二维对侧关系；下方左片段和右带又有串列间隔。R0_1 / R3_4 对应不同提议水平的对侧关系，R1_2 / R4_5 表示下方串列。这样可以同时保留**横向跨暗谷**与**同侧沿轴间断**，不必硬选一种 family。

但 S65_1 把上方多层响应压成一条穿过中间的长弦，掩盖局部层级；原场剖面并不全程高于两侧。暗区依旧向外渗出。这是局部组织可表达、内部几何不足，非完整解析成功。详见 [原场见证](../output/morphology_object_v2/figures/GM_RM019_f0350_g332_object_witness.png)。

### PV002 另外三帧：保留变化，不追踪节点

![A021 对象](../output/morphology_object_v2/figures/GM_RM017_f0330_g115_object.png)

A021 的下侧条带和右端强核清楚；S65_2 是穿过上肩的斜弦，未准确跟随完整下侧；上方小片段和右边界片段不足以构成完整对侧。原图可读性高于当前段表示。

![A085 对象](../output/morphology_object_v2/figures/GM_RM017_f0353_g177_object.png)

A085 上侧三短片段、下侧端团和弱串列可见。图表达了两侧及上侧串列，但 S80_5 / S65_8 的直弦跨越下方弯曲/碎片化组织，不能当真实连续路径。亮端与连续底板并不是一回事。

![A162 段层失败](../output/morphology_object_v2/figures/GM_RM017_f0378_g254_object.png)

A162 仍有多个下方亮核及短片段，却没有候选段满足预设延展支持约定。因此明确输出 `MORPHOLOGY_NOT_RECOVERED_AT_SEGMENT_LAYER`。这里需要的可能是“紧凑组 + 间隔 + 串列碎片”，不是再把长宽比放松到出段为止。没有做时序匹配、平台补偿或身份重建；这些历史同车图只展示不同帧组织及表示的得失。

### GM11 A312：只表达了下半部，整车坐标不能用一根轴代替

![GM11 对象](../output/morphology_object_v2/figures/GM_RM011_f0256_g77_object.png)

y≈85、98、120 的横向短带分别得到局部候选，层间暗谷可以回看。可是上部纵向/弯曲结构和端部亮组没有形成相应 segment。图中多个横段被称 `opposite`，仅指段与段之间的相对几何；**不能解释成车辆左右两侧**。一个整车可能有多个局部轴，当前表示尚未把这种局部层级保留下来。

### M5 A060：有图不等于有可辨认整体

![M5 不清案例](../output/morphology_object_v2/figures/GM_RM017_f0344_g152_object.png)

下方几个亮核及破碎侧边可见，但上部组织不清；程序仍产生段和 `opposite`。保留 `MORPHOLOGY_UNCLEAR` 的人工审阅结论，不把算法关系当作澄清。人工审阅单独保存在 [review_notes.json](../tasks/morphology_object_v2/review_notes.json)，没有回灌核心构建函数；也没有为 442 个样本重新分类。

### 原场支持核验的分母

7 个 GT 记录共有 30 个候选段，全部有可复算的 I0 主弦/侧剖面；其中 19 个在相同灰度水平回看 I0 时，支持被分成多个原场连通片。27 条非嵌套关系都有 I0/I2 双路径；27 条平滑路径在 I0 同水平不能原样成立。这些是**提议与原场之间的结构核验结果，不是车辆特征发生率**。

没有把“具备 raw_check 字段”算成原场支持成功，也未给出全段人工接受率。逐例视觉审阅只支持上面的局部组/片段解释；连续性、真实桥和共同归属仍待定。27/27 的路径差异不意味着 27 条关系均被否定：两种场的独立连通路径都确实存在，改变的是水平和路径细节。

## 4. 结构干预：结构记录也必须接受反驳

仅对 A059 和 A441 各做一次 A–E，没有训练、阈值搜索或目标判别。每个变体重新构建完整对象；不沿用原图节点 ID 冒充身份不变。

![A059 五项干预](../output/morphology_object_v2/figures/GM_RM017_f0344_g151_interventions.png)

![GM19 五项干预](../output/morphology_object_v2/figures/GM_RM019_f0350_g332_interventions.png)

| 干预及精确操作 | 原场组织如何改变 | 对象重建暴露什么 |
|---|---|---|
| A：低于原场 q97 替换为源最小值 | 强核的原像素保留，峰肩/弱侧大幅消失 | 分位数落在替换后的常值底板，底板反被连通支持提议为巨大直段；A059 甚至仍有对侧关系。**伪段失败**，不能报告“节点少了所以更纯” |
| B：冻结上方条带中低于 q85 的部分替换为最小值 | 核附近弱支撑出现人工断口，核心未全部删除 | A059 粗对侧关系仍在，但暗种子迁向删除区域；GM19 上侧提议丢失、下方串列仍在。说明高层标签可漏掉支撑损伤，不证明弱支撑无关 |
| C：冻结中部矩形逐像素抬至至少原 q85 | 明确填高原暗区，原场双侧间隔被平台占据 | 新平台本身形成直段；暗谷种子转移到平台外缘，假设关系重新挂到平台上。**关系改变了意义，但名字还在** |
| D：交换两个等尺寸块，移走下侧部分片段 | 块内部像素与总直方图精确保留，组间距离/层位改变 | 候选段及连接端点改变；原场连续性被接缝同时扰动。不是“只改变关系、核绝对不变”的纯净物理操作 |
| E：固定种子 20260914 的全像素置换 | 灰度多重集精确保留，原二维两侧/暗内部组织消失 | 仍生成许多短段和对侧/串列关系。**语义生成过于宽松**，不能据图中有 `opposite` 就声称保留了车辆组织 |

B 冻结编辑范围为 x∈[0.32w,0.70w)、y<0.30h；C 为 x∈[0.18w,0.82w)、y∈[0.30h,0.70h)。D 交换 x∈[0.18w,0.70w) 上 y≈0.72h 与 0.34h 开始的两个高≈0.18h 块。它们是手工定义的同源显示干预区域，不是推断得到的车内 Mask。

每个 `*_comparison.json` 保存同尺度核在映射位置 2 px 内的**所有**兼容候选，以及同提议水平段的全部支持重叠，不做一一匹配、赢家选择或 relation identity。D/E 保存可逆像素映射。原节点/关系的 ID 是当次构建 ID，不能跨干预直接比较同名项。主要变化必须回到端点、支持与路径解释，而不是比较数量。

merge topology 的原图与干预版本都完整保存，静态图可展开查看。A/E 改变峰出生及合并关系；C 加入大片等值平台；D 改变两组之间的低谷路径。没有把树编辑距离压成一个组织损坏分数。

结论不是“某关系已被证明为车辆形态必要条件”。可支持的更窄结论是：这些例子的弱侧、间隔和二维布局参与可读的整体；现有提议/语义层尚不能忠实反映它们被破坏的程度。**发现平台伪段和打乱后的漂亮图后停止扩展解析规则**，没有补 car score 来挽救。

## 5. 原场与平滑场：职责不同，不能二选一

I2 能把局部核及肩部组织成阅读上更容易理解的中尺度组；I0 则揭示组内暗断口、弱支撑、局部细带和取样峰位。两者均是同源表示，不是两份独立观测。

本轮检查了原场邻域峰相对平滑峰的偏移、主弦及侧剖面、同水平片段数、独立鞍值、各自连通路径、平滑路径在 I0 中的实际灰度、暗区开放状态变化。它们作为相应单元/关系的属性与见证存储，没有归并成“平滑质量分数”。

值得保留的表述是“平滑提出组，原场约束组的解释”；当前还没有实现对每个提议自动作接受/拒绝。仅根据原场某一点低于阈值否决整个片段组，同样会丢掉有意义的非连续组织。下一步应区分 **continuous ridge、fragment group、unsupported chord**，不能把三者画成同一种实线。

## 6. 很小的 GT-release：停止在对象层，而非假装恢复

只有在 A059 原场、弱组和双路径见证被直接查看后，才写入 [wide_freeze.json](../tasks/morphology_object_v2/wide_freeze.json)，再首次解码宽窗口。固定 GM17 f344 native 坐标 `[990,900,1290,1080)`，300×180 px；面积约为原 chart 的 4.56 倍。窗口位置来自既有图像审阅的粗位置，**不是分析者盲选，也不声称自动产生搜索壳**。

## 8. 对上一轮结论的保留与修正

仍支持：连续场、尺度层级、二维布局、弱支撑与暗间隔不能被总强度或单个 blob 替代；树需联合二维位置解读。一个长段也可能只是多核/多片段组织的一种低级 primitive，BAND_CENTERLINE 不是唯一表示。

需要收紧：

- 上一轮 Hessian 方向实际涉及横向法向，且原来的方向平均不适合无向轴；不继承该方向量的语义。本轮直接保存无向 PCA 轴，仍不称物理车轴。
- 上一轮中位数填充不能保证暗内部真的被填高；本轮 C 明确抬到至少 q85，但会产生平台，必须记录干预伪结构。
- “结构干预破坏了原图组织”不能直接升级为“现有计算表示已捕捉其必要关系”。E 的图仍丰富，A/C 出伪段，直接否定这一升级。
- “暗内部”作为观察语言有用，但 seed-connected 低值连通区域并不稳定对应它；开放到 aperture 边界与车辆开放周边需要分开。
- “有了核、段、关系就得到车辆对象”不成立。现在得到的是可审阅假设记录，primitive 与语义之间仍缺少忠实映射。

未新跑 RSA/G2/R2B，因此不追加对其检测/定位能力的评价；本轮仅将旧 BAND_CENTERLINE/HOTSPOT 放在更一般的候选 primitive 层，而非车辆定义层。

## 9. 九个问题的简答与下一步

1. **至少几个真实 patch 能否形成回指结构对象？** 能形成可检查记录，A059/A441 的局部组间组织最清楚；不能称整车已解析，GM11 仅部分，A162 段层停止，A060 不清。
2. **核、段、关系、暗区各做什么？** 核定位局部突起；段提议中尺度支撑；关系保存二维组织与合并条件；暗区保存间隔/开放见证。都不能单独定共同归属。
3. **哪些标量只能辅助？** 峰强、偏移、尺度、长宽比、距离、角度、鞍值、暗区面积/触边状态只能描述所依附结构，不能代替场、路径和关系语义。
4. **树与 geometry 如何互补？** 相同合并顺序可对应不同布局；本轮转置夹具保持相同合并鞍值却改变路径坐标。树加坐标仍不足以定物理归属，但比裸树更可审阅。
5. **平滑提议回原场支持多少？** 30 个 GT 段全部有可验证原场见证，不等于30个被接受。19 个同水平原场支持碎裂；27 条平滑路径均不能原样同水平回用。视觉支持限于具体组/片段，不报告伪接受率。
6. **干预破坏什么？** A/B 损伤弱肩/片段支撑，C 改变暗间隔，D 改变层位/距离并引入接缝，E 摧毁二维组织。表示却会重建伪段与同名关系，这是最重要的反证。
7. **去掉精确 GT 能否重组？** 该冻结宽窗中核多有兼容复现，但主段提议和对象关系未恢复；SAR 场中信息仍可见。
8. **最大瓶颈？** 不是缺少一个更强标量，而是 **“中尺度候选 → 原场支持的组织语义”不忠实且依赖 aperture**；平台、曲段、碎片和底纹会让命名与实际结构脱节。图的计算预算是第二道暴露的问题，不应靠排名绕过。
9. **下一步仅两条：** ① 研究原场支持的局部片段组，把连续 ridge、允许暗断口的 fragment group、无支持弦分开，并显式保留平台/弯曲/分叉不确定性；② 研究不依赖全 aperture 分位数的局部关系构建，在同一个冻结宽窗内保留多种归属，不通过增加预算、选最强组或统一评分完成“恢复”。这两条仍是表示研究，不是本轮已实现的机制。
