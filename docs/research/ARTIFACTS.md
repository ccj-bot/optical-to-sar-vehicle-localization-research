# Git与外部研究资产

Git保存经过逐文件审核的源码、配置示例、研究结论、失败记录、字段/数据合同与复现说明。

原图、视频、权重、数组、数据库、Parquet、完整生成输出和压缩包不在本次提交候选中。原始数据、确认标注与冻结结果继续原位保留；Git上的源码不是这些数据的备份。

本次候选不包含本机助手配置、模型网关设置、环境目录、第三方依赖副本、未完成权重下载或个人路径。历史删除记录与本次成果保存无关，不随本次提交。

`SOURCE_PROVENANCE.json`列出公开候选文件的本地来源相对路径、源哈希、候选哈希和明确改动。路径是定位说明，不表示其所指大型本地输出已经公开。

后续提交按研究主题分批。旧失败应以历史状态保留，不能混入当前主线成绩；当前基线更新应另建版本，不覆盖已有封存。
