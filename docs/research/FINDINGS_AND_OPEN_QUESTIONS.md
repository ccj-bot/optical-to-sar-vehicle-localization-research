# 关键设想、验证与仍待解决的问题

下表保留成功与失败，不把已执行机制重新当作尚未开始的计划。引用路径是仓库外本地证据索引；来源哈希见`SOURCE_PROVENANCE.json`。

|问题/设想|已经执行的验证|支持范围与后续问题|
|---|---|---|
|公共补偿后累积能否有用|2026-10-23的15个查询中，多帧均值15/15优于单帧，补偿均值14/15优于不补偿；加权仅7/15优于普通均值|支持这些开发查询的图像表达/预测；不证明车辆归属。保留普通补偿均值作为强基线|
|局部核心能否带动整车|GM17固定267条件位置、18个非模板时刻，外围NCC配对变化中位数均未改善；较强核心子集仅4/18为正|该版核心位移不能普遍解释整片外围；应区分对象参考位置与视角相关支撑，不由失败推出对象消失|
|预测更好是否找对车|GM19某查询预测改善6.27%，却选中远曲亮带；9个可读响应点均在待审车辆框外|评分提升不足以建立指定目标归属；保留邻车/公共结构竞争与光学方位检验|
|完整L形及宽度能否恢复|双边未稳定优于最佳单边；部分8至96工作像素宽度在同一可见边下产生完全相同预测|没有观测到的另一边不能由模型名称补成测量；需互补时相真正减少等价解释|
|多时相共同优化是否会推偏|2026-10-29 R35五时相模型的响应预测分数提高，但六车中心移动9.2–19.8原生像素|窄矩形边响应模型可通过移动整框去贴亮线；整体范围不等于散射边界|
|后续观测能否回溯早期解释|GM19的21帧原型已回写早期片段归属，时序连接臂优于该次固定/无连接开发对照|机制已运行；不自动证明归属改对。后续应检查指定对象及邻车争用|
|一次初始化后的SAR反馈定位|另一组双车5时刻链路已运行；3条可用待审参考下IoU平均0.760→0.802|支持该初始化条件下的开发增量；旧单车轴对照约0.805，不能只挑弱基线；完整尺寸仍来自先验|

## 当前可检验方向

1. 将对象整体位置、可变局部响应和未观测范围分开表达。
2. 在同一共享观测域比较公共补偿、固定模板、可变支撑和邻车竞争，保留所有失败样本。
3. 时序前缀冻结后的后段预测，与利用后段修正前段的离线回溯分开报告。
4. 在已暴露的R35上先进行开发诊断，之后以其他段/场景检验迁移；相邻帧、片段和像素不当作独立样本。

当前三车连续参考可以帮助找错误发生的时刻和结构，但其轨迹由配准生成、尺寸由先验继承。因此它尚不能认证同一算法的定位误差、真实车长或物理散射来源。
