# 发布前独立语义复核

日期：2026-11-02。复核对象是本次发布的研究叙述、相关源码和已保存报告。这里的“独立”指重新按实际输入、计算量、证据来源和可替代解释审查既有说法；由同一执行者完成，不冒称第三方审稿或独立数据复现。本轮未运行新的科研实验。

## 复核方法

对每项结论检查四个问题：代码实际计算的量是什么；评价参考是否独立于生成过程；实验改变了哪些信息和自由度；还有哪些解释与结果相容。检查发现的叙述问题在当前节点记录中修正，既有失败结果和源码保留。

## 本轮改变了哪些结论

1. 将“修好了定位/逐帧重画”收紧为“配准导航后视觉审核的近似参考修订”。版本差保留，不写成精度增量。
2. 将“未来预测”逐项限定为相应条件读出或固定前缀检验；不混入后验选分支、回溯和当前背景信息。
3. 将“为什么得到这些结果”拆成代码可确认的原因和仍相容的机制假设。未把高分、稳定或多数意见当作物理机制证明。
4. 保留已执行的正结果：补偿/累积、条件初始化后SAR反馈、回溯更新、PERSON集成与HOLD修复。边界收紧不等于否定这些实际增量。
5. 公开源码保持与冻结运行的对应关系；历史v1和过时文档明确注明版本与失败，不把旧叙述作为当前结论。

## 与下一步的关系

最值得检验的是：在同一共享观测上，允许局部支撑变化的对象解释，是否比公共补偿与固定模板更能保持指定车辆关联，并避免转移到邻车/公共亮带。若只有图像分数增加、却无法保持对象关系，则该方法尚未解决目标任务。

范围研究须检查新时相是否提供新的边或相对约束。若只有同一亮带反复可见，固定车长或额外标注余量都不能填补可辨识性缺口。当前参考可用于挑出关键反例和设定开发验证，但不能充当其生成算法的独立真值。

科学问题仍开放：真实响应来源、远端轮廓、同步与配准误差影响、跨场景迁移，以及物理机制唯一性。它们没有因源码提交或文档重写而闭合。
