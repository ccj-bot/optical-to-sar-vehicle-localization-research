# SAR vehicle morphology object：三条表示路线的小规模探索

日期：2026-09-13  
分支：`feature/oty2-sar-vehicle-morphology-object`  
范围：已知车辆 GT 内部的 SAR 显示强度场；不是检测器、分类器、响应 Mask 或物理散射中心恢复。

## 结论先行

这轮没有找到一个可以不加解释地称为“车辆对象”的单一表示，但得到一个有用的边界：

> 对 A059 这类清楚案例，**原场的多水平合并顺序**能表达“主侧多个核先变成延展段、对侧弱段后参与”的组织；**单独的树不够**，必须和峰的二维位置、方向和暗间隔一起看。

> “核→段”可由局部横向曲率脊给出候选段，但它对弱车辆和 GM11 多层结构非常敏感，q82 只是可读性旋钮；不能把脊连通域当作车辆部件。

> 同源破坏最直观地支持了关系信息：A059 只保留强核后，长带仍有残片但对侧组织和连续峰肩明显消失；填暗内部会抹掉宽度／开放性线索；打乱像素布局则保留大致灰度分布却摧毁所有空间组织。这是显示表示干预，不是物理反事实或分类实验。

因此下一步值得保留的是：`连续原场 + 多水平 merge relations + 候选段的二维几何 + 暗间隔/开放性`，而不是只保留峰数、组件数或总能量。完整 merge tree、段级闭合语义、跨帧对应均未宣称完成。

## 2. 路线 A：多水平合并结构

### 做法

对每个像素灰度从高到低激活，在 8 邻域下维护超水平集的连通根。相同灰度在一个 atomic batch 中处理，避免平顶被伪造出顺序。树节点保存出生灰度、鞍值、子节点、二维像素位置、边界标记和持久性；所有节点写入 JSON。图中只画持久性较高的最多 10 个峰以保证可读，未画节点没有被删除。

这不是最终的 binary mask：q90/q75/q55 等线只是观察不同水平的结构，树记录的是整场的合并关系。

### A059 读图

![A059 merge tree](../output/sar_vehicle_morphology_object/figures/GM_RM017_f0344_g151_merge.png)

A059 原场微结构有 857 个局部峰、835 个合并节点；σ=2 的显示场减少到 74/73。这不是“真实散射中心由 857 变成 74”，而是平滑改变了显示场的拓扑复杂度。σ=0 的树把主带、对侧短段和底纹都混在一张树里；σ=2 的树更能读出主侧高峰先形成组、较低鞍部才接入其他组，但空间位置不在树的横坐标中，必须回看左图。

### 跨案例表现

- GM17 长带和端团案例：树能记录“先局部、后组合”，与原图的多水平生长一致。
- GM11 f256：树可以保留多层短带的不同出生／合并水平，但树本身不会告诉读者这些分支是在同一长轴上还是上下平行，二维坐标必不可少。
- GM19 f350：对侧组作为较晚合并的分支较符合读图，但不能由此证明两组属于同一物理车辆部件。
- 弱例 A060：树同样很复杂（σ=0 为 618 峰、609 合并），说明“树的存在／节点多”不是车辆形态解释；它主要反映底纹和显示噪声。

### 路线 A 的失败点

1. 原场树对 speckle 过敏，微小纹理也出生为分支。
2. 平滑使树容易阅读，却会把低谷抹平并制造连接；尺度不是物理部件大小。
3. 树的分支顺序没有方向和相对位置；只看 dendrogram 会丢掉长轴、对侧和开放周边。
4. 边界峰和 GT 裁剪边缘会参与树，必须保留 boundary flag，不能当完整车辆响应。

## 3. 路线 B：核→段→组合

### 做法

先在 σ=2 场计算 Hessian 最小特征值，得到局部横向曲率响应；q82 超水平区域只用于产生一张“临时 ridge/segment”可视图，再计算段质心和局部方向。没有给段命名，也没有规定“一个段＝一个部件”。旧研究中的 `BAND_CENTERLINE` / `HOTSPOT` 可被理解为将来可能挂在这一级的低级 primitive，但本轮没有复用其人工带卡作为监督。

![A059 核、候选脊和破坏实验](../output/sar_vehicle_morphology_object/figures/GM_RM017_f0344_g151_relations_destruction.png)

### 真实观察

- A059：横向曲率脊能把顶部延展带拆成许多短片段，峰核作为片段内突起；但 q82 下底部弱组也产生片段，说明“段”需要和灰度、位置、低谷关系同时保存。
- GM11 f256：多个上下层短带和纵向过渡同时出现。该表示能显示层级候选，但交叉处会断裂或产生很多小段，不能直接压成一条纵向中心线。
- GM19 f350：顶部／底部不等强组能被找到，然而段方向和连接并不唯一；这正是应该保留候选关系而非固定部件标签的例子。
- A060：候选段约 55 个，几乎遍布细碎场；这是该路线的明显失败案例。它告诫我们：可计算的脊不是“车辆段”。

### 当前最自然的对象层次

```text
I(x,y) 原始连续显示场
  ├─ nuclei：局部峰及其持久性/尺度
  ├─ provisional segments：峰肩、脊片段、二维方向（候选）
  └─ organization：串列、对侧、开放周边、相对强弱和暗间隔
```

其中 `provisional` 很重要：段可以跨越纹理、在弱支撑处断开，也可能只是扇形弧或车地混合。段的证据应回指原场，而不是回指一个二值结果。

## 4. 路线 C：暗间隔与开放区域

本轮以案例条件的 q40 低场覆盖图和暗区填充干预来观察“没有亮响应的地方”。这不是自动估计车辆内部：GT 中心不必是物理中心，暗值也可能是成像几何、阴影、低响应或显示范围。

在 A059，顶部主带和底部弱段之间的暗内部给出横向间隔；它让两组响应看起来是一个有宽度的开放组合，而不是两个无关亮点。把内部填成中位数后，亮组仍在，但“对侧—暗内部—主侧”的关系不再明显。GM11 f256 的低场中，层间低谷帮助区分多条短带；若把所有低谷都视作车内空区，又会错误解释扇形背景。

所以暗区应表示为**关系**：某两组峰／段之间存在低谷、是否能在指定水平连通、连通是否绕行 GT 边界、以及区域是否向观察窗边界开放。它不应成为一个独立的“黑色车辆区域”或阈值 Mask。

## 5. 同源结构破坏：什么是真正被保留的形态信息

![GM11 多层短带破坏实验](../output/sar_vehicle_morphology_object/figures/GM_RM011_f0256_g77_relations_destruction.png)

四种干预均从同一个 patch 生成：

1. `strong_nuclei_only`：低于 q90 的值置为最低值；保留亮核，删除峰肩和弱段。
2. `weak_support_removed`：低于 q65 的值抬到 q65；压平低谷和弱背景。
3. `dark_interval_filled`：中央相对暗矩形填为中位数；测试暗内部／开放性视觉线索。
4. `spatial_layout_shuffled`：固定随机种子打乱像素，保留近似直方图，破坏邻域关系。

A059 中，强核保留后顶部主带还有少量亮块，但长向支撑、对侧弱段和整体间隔显著减弱；暗间隔填充后两组亮响应尚在，却失去开放周边的解释；随机布局后只剩灰度颗粒，原来“有长度、有两侧、有低谷”的组织消失。GM11 中强核仍保留几个层级亮点，却不再自然形成连续的多层短带。A060 的原图本来就没有稳定整体，破坏前后只能说明底纹组织不可靠。

这些观察支持“关系和弱支撑确实承载外观信息”，但不能写成分类性能或因果证明：干预改变了显示图像本身，且 q90/q65/中央矩形都是人工观察操作。

## 6. 哪些假设被推翻

- **merge tree 单独就是 morphology object**：弱例也能产生复杂树；树必须带二维位置和原场回看。
- **局部峰自然就是响应单元**：σ=0 会产生数百个纹理峰；峰需要尺度、持久性和边界语义。
- **ridge 连通域就是段**：GM11 交叉、GM19 弱组和 A060 都会产生伪段；当前只能叫 provisional。
- **删除低值不会影响车形**：A059 的侧带延展、对侧短段和宽度感都会减弱。
- **暗处只是空白背景**：填暗内部会改变开放组合的读法；但暗处也没有唯一物理含义。
- **保持直方图就保持形态**：空间随机化后灰度分布仍在，二维组织完全消失。
- **一个统一 family 或固定峰数适合全部案例**：GM17、GM11、GM19 的结构和弱例均不支持。

## 7. 下一步只保留三个机制

1. **原场约束的尺度空间段**：使用脊／方向作为候选，但要求片段在原场有可回指的连续支撑；同时保存断裂，不用粗平滑补齐。
2. **带空间坐标的 merge relations**：保留每个峰的二维位置、同侧／对侧相对关系、出生与合并鞍值，避免只画无位置树。
3. **暗间隔／开放性关系**：记录组间低谷、向 GT 观察窗边界的开放路径和未连接关系，禁止自动解释为车内阴影或 Mask。

暂不继续：完整自动分段、统一 family 聚类、跨帧单元匹配、平台补偿、背景对照、AUC、检测器和物理散射命名。
