# PERSON P0 之后的深化研究候选方案（独立审阅前草案）

> 状态：`POST_P0_RESEARCH_PLANNING_ONLY`  
> 日期：2026-08-25  
> 边界：本文不是已冻结的 P1 协议，不授权运行 P1，不修改 P0 结论或冻结模型。

## 1. 总目标

P0 已证明：在当前 R01/R04 SAR 伪彩图像域协议下，可以仅用 PERSON 外背景估计公共表观运动，并把静止 PERSON 框中心残差压到 PERSON 尺度以内。

下一步不应直接训练分类器或做光学—SAR关联，而应先回答：

> 去除公共图像输运后，PERSON 附近还剩下哪些可重复、可条件化、可审计的图像域响应；这些响应能否在完整留出场景中稳定复现，并且不主要由显示变化、框来源、多人融合或扇面边界驱动？

研究对象仍是目标、场景、载体、成像处理和显示链共同形成的条件性图像域响应，不是人体固有 RCS 模板。

## 2. 建议路线

建议把深化研究拆成一个桥接审计和三个正式阶段：

1. `B0`：P0→P1 桥接审计；
2. `P1A`：测量定义与可靠性；
3. `P1B`：条件响应发现；
4. `P1C`：完整留出复现与 P2 资格门。

在 `P1C` 通过前，不进入 P2，不生成最终 SAR 框，不把光学先验变成最终定位器。

## 3. B0：P0→P1 桥接审计

### 3.1 为什么需要桥接

P0 只在 R01ZF 选型、R04ZF 验证。其他 run 是否具备足够背景锚点、是否处于冻结模型可用域、显示变化是否超出 R01/R04 覆盖，目前尚未验证。

因此，不能因为 P0_PASS 就默认所有 PERSON 帧都可以安全补偿。

### 3.2 只读预检内容

- 清点全部 run、帧数、PERSON ID、人工框/插值接受框来源；
- 清点已知静止、行为变化、多人邻近、20 m 边界和弱响应条件；
- 检查每个 run 是否能使用冻结 P0 表示、遮罩和背景锚点标准；
- 按 run 统计可比较率、背景留出残差、显示变化层和失败原因；
- 明确哪些 run 只能用于探索，哪些可以保留为完整确认集。

### 3.3 桥接边界

- 不重新选择 M1/M2/M3；
- 不使用 PERSON 框位移拟合或挑选公共运动；
- 不因困难帧而放宽锚点或边界标准；
- 若冻结 P0 在某类 run 中不可用，该类样本必须标记不可比较，不能静默补偿。

## 4. P1A：先定义“测什么”，再谈规律

### 4.1 分开两个观测通道

#### 通道 A：补偿后位置残差

\[
r^P_{i,t,\ell}=\Delta c_{i,t,\ell}-\hat u_{t,\ell}(c_{i,t})
\]

它仍是框中心的图像坐标剩余量，不等于人体独立物理运动。

应同时携带：背景留出残差、锚点覆盖、显示变化层、lag、框来源和边界风险，不能只保留一个残差标量。

#### 通道 B：单帧局部响应形态

在 PERSON 接受框及固定安全邻域内，建立只属于显示域的形态测量：

- 响应是否存在、是否弱响应；
- 高响应区域紧凑性与碎裂度；
- 峰值数量、峰—脊结构和主轴支持；
- 径向跨度与切向跨度；
- PERSON 区相对局部背景环的对比；
- 响应中心相对接受框中心的偏移；
- 多人邻近时是否发生融合；
- 20 m 边界处是否截断或只部分可见。

这些量优先基于梯度、秩、分位和局部相对量，不把伪彩 RGB 直接解释为物理幅度或 RCS。

### 4.2 测量可靠性先于效应分析

每个候选测量先通过以下审计：

- 小幅裁剪扰动下是否稳定；
- 人工框与全部接受框结论方向是否一致；
- 不同显示变化层中是否只是全局显示分布的代理；
- 同一 PERSON 的相邻可比较帧中是否具有可解释的重复性；
- 失败时能否明确归入弱响应、多人融合、边界截断、去相关或标注不确定性。

若测量本身不可靠，不进入条件规律分析。

## 5. P1B：条件响应发现

### 5.1 主要条件变量

- 距离与方位；
- lag 和背景配准置信度；
- 显示变化层；
- PERSON 框尺度和框来源；
- 单人/多人邻近；
- 距 20 m 边界和扇面侧边的距离；
- 光学提供的行为状态与时间连续性，但不由光学指定 SAR 响应位置。

### 5.2 分析单位

- 单帧形态：`run_id × target_id × frame`；
- 时序变化：`run_id × target_id × frame_pair × lag`；
- 汇总时先在 target/run 内聚合，再跨 run 比较，避免把大量重叠帧对当成完全独立样本。

### 5.3 直接证据优先顺序

1. 原始 SAR 伪彩图和局部响应叠加图；
2. 条件分层后的直接测量分布；
3. 人工框/全部接受框敏感性；
4. 几何匹配的非 PERSON 背景对照区；
5. 最后才使用稳健回归或分层模型概括效应。

不以分类准确率、相关系数或大网页汇总替代直接图像证据与失败病例。

### 5.4 对照设计

- 非 PERSON 对照只从有效扇面内、避开所有 PERSON 和边界的局部区域取样；
- 对照应尽量匹配距离、方位、局部有效像素和显示变化层；
- 不把 PERSON 框位移复制给背景；
- 对照区域不是负样本 SAR 框，也不进入最终定位。

## 6. 数据划分原则

### 6.1 R01/R04 的新角色

R01/R04 已在 P0 中被查看，不能再作为未暴露的 P1 最终确认集。它们可以作为：

- 静止 PERSON 控制；
- 测量可靠性和失败模式研究；
- P0 补偿解释的校准材料。

### 6.2 P1 发现与确认必须按完整 run 划分

- 在查看候选特征结果前冻结完整 run 级发现集和确认集；
- 不做随机帧拆分，避免相邻帧、同一 PERSON 和相同场景泄漏；
- 确认 run 在特征、阈值和图示选择冻结前不得参与决策；
- 若剩余 run 数量不足以支持独立确认，应明确降级为探索性研究，不强行宣布 P1_PASS。

具体 run 分配必须在 B0 数据审计后决定，本草案不预指定“哪个 run 一定作为成功确认集”。

## 7. P1C：确认性问题与通过门槛框架

正式门槛应在 B0/P1A 后预注册，候选框架如下：

1. 至少两类非冗余响应测量在完整留出 run 中复现发现集的效应方向；
2. 结论在人工框子集与全部接受框中方向一致；
3. 结论不能主要由显示变化层、单一 run、单一 PERSON 或边界样本驱动；
4. 几何匹配背景对照不能产生同等强度的“PERSON规律”；
5. 最差病例可归因并保留，不能通过删除困难条件通过；
6. 补偿不确定度较大时，位置残差相关结论必须降权或标记不可比较；
7. 不使用光学轨迹或人工 physical_target_id 在运行时选择正确 SAR 响应。

若失败，建议结论收缩为：

`CONDITIONAL_PERSON_RESPONSE_NOT_STABLE_ENOUGH_FOR_P2`

而不是放宽门槛进入光学—SAR关联。

## 8. P2 之前必须得到什么

只有 P1C 通过后，P2 才能获得一个有限、明确的 SAR 证据接口，例如：

- 允许使用哪些响应测量；
- 每个测量的方向、尺度、置信度和不可比较条件；
- 多人融合、边界截断、弱响应的状态码；
- 哪些量只能用于候选支持，不能生成最终框；
- 光学先验如何只限制时间/方位搜索壳，而不指定 SAR 亮点。

## 9. 建议交付物

1. `P1_DATA_AND_SPLIT_AUDIT.md`：run/target/框来源/条件覆盖和完整留出方案；
2. `P1_MEASUREMENT_DEFINITIONS.md`：位置残差与局部形态量的计算定义；
3. `P1_FEATURE_SCHEMA.json`：字段、单位、来源、运行时可用性和禁止解释；
4. `P1_RESPONSE_ATLAS`：原图、叠加图、条件分层和失败病例；
5. `P1_DISCOVERY_RESULTS`：只用发现集；
6. `P1_FROZEN_VALIDATION`：完整留出 run 直接验证；
7. `P1_CONCLUSION.md`：明确 `P1_PASS` 或失败状态，并决定是否具备 P2 资格。

## 10. 建议执行顺序

1. 完成独立方案审阅；
2. 只读审计全部 run、PERSON、框来源和条件覆盖；
3. 冻结 P1 的发现/确认 run 分配；
4. 冻结测量定义和失败状态；
5. 在发现集做直接可视化与测量可靠性审计；
6. 只保留有直接图像证据、可靠性和背景对照支持的测量；
7. 冻结 P1C 门槛；
8. 一次性运行确认集；
9. 输出结论并停止，不自动进入 P2。

## 11. 当前不建议立即做的事

- 不立即训练 PERSON/背景分类器；
- 不直接从补偿后框残差推断人体运动；
- 不建立人体固有 RCS 模板；
- 不把光学轨迹投到 SAR 后直接选择亮点；
- 不用 R04 或后续确认 run 反复调参；
- 不创建、移动或自动修正 SAR 框；
- 不因 P0_PASS 就把所有 run 视为可补偿。

## 12. 需要独立审阅的问题

本草案请审阅者独立判断：

- 研究问题是否足够窄且可证伪；
- B0、P1A、P1B、P1C 的顺序是否合理；
- 是否存在仍然循环使用 PERSON 框或 P0 结果的风险；
- 完整 run 留出是否足以控制时间/场景泄漏；
- 候选测量是否仍受伪彩显示链过度支配；
- P1 到 P2 的资格门是否过松、过严或缺少关键条件；
- 是否应删减、重排或增加阶段。
