# PERSON P0 后深化研究方案独立科学审阅

> 审阅结论：MAJOR_REVISION_REQUIRED  
> 审阅日期：2026-08-25  
> 范围：只审阅方案与现有证据，不运行 P1，不修改草案，不重新拟合 P0，不读取 old_work。

## 一、结论先行

草案的研究方向是合理的：先把公共图像输运去混杂，再研究 PERSON 附近的条件性显示域响应；保持光学只提供时间、行为与方位搜索先验，SAR 保留最终定位权；不训练分类器、不把框轨迹解释为人体独立运动。这些边界应保留。

但当前草案不能直接作为“P1 确认性协议或 P2 资格门”。主要有四个阻断项：

1. **现有四个 run 都已暴露于 PERSON 响应观察，不存在真正未见的 P1 确认集。** 既有多维探索报告已经分别把 R04 解释为单人响应发现、R01 解释为融合失败对照、R02 解释为多人及显示跳变、R03 解释为 20 m 截断，并提出了后续检验假设。R02/R03 因而不能再称为未暴露确认集。
2. **独立数据单位太少且条件与 run 严重混杂。** 全部只有 4 个 run；R02 仅 23 帧但有 4 个目标，R03 仅 37 帧且只有 1 个目标。单人、多人融合、显示跳变、外边界截断几乎各自集中于特定 run，因此难以区分“条件效应”与“run 特异性”。
3. **测量仍有明显的框条件循环。** 852 个接受框中只有 251 个是原生人工框，600 个来自线性插值。若以接受框中心和框尺度定义裁块、峰值、紧凑性或响应中心偏移，可能测到人工选框和插值规则，而不是可在定位前独立计算的 SAR 证据。
4. **P1C 门槛仍是定性框架。** “至少两类测量方向一致”不足以判定可复现性；尚未固定主终点、最小效应量、覆盖率、缺失率、局部配准误差预算、相关样本处理和 P2 运行时可计算性。

因此建议把现有四个 run 全部明确为**开发/探索语料**。当前可以继续完成 P1 的测量定义、误差审计和病例图谱，但不得据此宣布 P1_PASS。真正的确认阶段需要新的、封存的独立 run；若暂时没有新数据，应以 P1_EXPLORATORY_ONLY_NO_BLIND_CONFIRMATION 结束，并保持 P2 不开放。

## 二、审阅依据与事实核验

- P0 的结论成立于冻结协议：R01 选型、R04 完全留出；579/579 帧对可比较，578/579 相对 M0 改善；静止 PERSON 补偿后 P90 为 3.557 px（全部接受框）和 5.029 px（人工端点）。这只证明公共图像输运达到 PERSON 尺度内的去混杂资格，不证明亚目标结构已被精确配准。
- 当前契约记录 4 个 run、398 帧、11 个 run 内 PERSON ID、852 个接受框，其中人工原生框 251、线性插值框 600、人工调整插值框 1；没有原始幅度、复相位、平台位姿，也没有经过验证的物理同步。见 research_contract_v1.json 第 31–42 行。
- 既有 RESEARCH_INTERPRETATION_V2.md 第 9–14、31–61、86–90 行已经对四个 run 的 PERSON 响应及失败类型作出观察并用于形成假设。因此“只因 P0 没用 R02/R03，就把它们当作 P1 盲确认集”不成立。
- 只读元数据核验显示：R01 为 142 帧/3 个目标，R02 为 23 帧/4 个目标，R03 为 37 帧/1 个目标，R04 为 196 帧/3 个目标。全部 398 帧的同步状态均为 NOMINAL_INDEX_FPS_ZERO_OFFSET_UNVERIFIED，现有光学记录中也没有已定义的 behavior 字段。
- 对 P0 最差背景帧、最差 PERSON 帧以及 R01/R02/R03/R04 代表性局部图的直接复核，确实能看到局部去相关、多人融合、整幅显示变化和边界截断等不同失败形态；但这些形态与 run 高度绑定，当前不能视为跨 run 复现。

## 三、对草案各部分的独立判断

### 1. 研究问题

总问题方向正确，但“还剩下哪些响应”过宽，容易在大量候选特征中事后挑选。正式研究至少应拆成两个可证伪问题：

1. **单帧位置特异性：** 在预先限定的可比较条件中，预定义 SAR 响应分数在 PERSON 参考位置是否稳定高于同距离、方位、有效像素和局部结构匹配的非 PERSON 对照位置？
2. **时序一致性：** 在冻结 P0 补偿及其局部误差预算下，预定义响应是否在 lag 1/3/5 上比固定背景或空间偏移对照更接近预期位置，并且不由插值框的平滑轨迹制造？

弱响应、多人融合、边界截断和显示跳变更适合作为覆盖/弃权状态与失败分层，不应同时被当成多个可自由选择的成功终点。

### 2. 阶段顺序

B0 → P1A → P1B → P1C 的逻辑大体正确，但应调整为：

- B0 增加“数据暴露与证据来源登记”，不得在看过目标响应后再挑选最容易成功的确认 run。
- P1A 与 P1B 可合并为一个明确的开发阶段，避免把连续的特征设计与筛选包装成相互独立的证据。
- 单帧形态与补偿后时序应分成两条通道。冻结 P0 在某 run 不适用时，只阻断该 run 的时序结论，不必阻断其单帧显示域病例研究。
- 光学行为应从 P1 确认性核心移出。当前同步未验证且数据中没有冻结的 behavior 定义；应在 SAR 测量冻结后另设同步/光学先验审计，或留到 P2。

### 3. 数据划分

“完整 run 划分”优于随机帧拆分，但在当前数据上仍不充分：

- 四个 run 都已被查看并形成了响应假设，应全部标记为开发/探索数据。
- 现有数据可以做留一 run 稳定性检查或病例复核，但只能称内部稳健性，不能称独立确认。
- 真正确认应以未暴露的 acquisition group 为单位封存，至少记录场景、采集时段、载体/处理配置和显示链版本；若这些元数据缺失，结论只能写成“当前语料内复现”。
- 新确认数据最好包含至少两个独立采集组，并让单人、多人、显示变化和边界条件在不止一个 run 中出现。否则草案中“不能由单一 run 驱动”的门槛实际上不可检验。

### 4. 测量定义

正式冻结前必须补上以下约束：

- 每个候选量给出公式、输入表示、平滑尺度、阈值来源、单位、缺失条件和禁止解释。
- 优先在扇面极坐标/物理尺度中报告径向米制跨度和切向弧长；不能默认不同距离处相同像素跨度具有相同物理含义。
- 主分析以人工原生框为参考；插值框只做时序覆盖和敏感性，不把大量相邻插值帧当作独立样本。
- 传给 P2 的分数必须能在任意 SAR 候选位置或搜索壳内计算，不能把真实接受框中心、宽高或 physical_target_id 作为运行时输入。人工框只能用于离线评价。
- 除匹配背景环外，增加固定规则的空间偏移/局部硬背景对照，检验响应是否真正集中于参考位置；这些是评价区域，不是新 SAR 框。
- 对时序位置残差建立**目标位置局部的 P0 误差预算**：至少包括邻近留出锚点残差、锚点空间覆盖/外推距离、显示变化层和标注来源。全场背景残差中位数不能代替目标位置的预测不确定度。
- P0 的 lag 1/3/5 使用不同冻结模型，不能把跨 lag 残差差异直接解释为速度或动力学；除非另行验证，不外推到更长 lag。
- 对显示链至少保留原始伪彩、梯度/秩和 JET 索引代理的表示敏感性。它们仍都是显示域代理，不得升级为幅度或 RCS。

### 5. 证据门槛

建议把“至少两类测量方向一致”改成少量、可计算的冻结门槛。每个主终点至少固定：

- 明确的比较对象和效应量；
- 最小有意义效应，而不只是方向；
- 目标/run 级覆盖率、不可比较率和缺失原因；
- 以 target/run 或时间块为聚类单位的区间，禁止把重叠帧对当成独立样本；
- 人工原生框主分析和全部接受框敏感性的角色；
- 最差分层是否仍保持最低性能；
- 与匹配背景及空间偏移对照的差异；
- P2 运行时可计算性与弃权条件。

当前只有极少独立 run，不宜依赖常规 p 值或复杂分层模型制造确定性。应优先报告逐 run/逐 target 的直接效应、区间、病例图和失败率。

还应区分不同终止原因：

- 没有未暴露确认数据，是证据不足，不是 PERSON 响应为阴性；
- 测量在开发数据中不可靠，是测量失败；
- 冻结测量在真正留出数据上不复现，才是 CONDITIONAL_PERSON_RESPONSE_NOT_STABLE_ENOUGH_FOR_P2。

## 四、建议删减与替代路线

### 建议删减

1. 暂时删去 P1 核心中的光学行为变量。
2. 将长特征清单压缩为不超过两类主测量族，其余全部标记探索性。
3. 合并 P1A/P1B 为开发阶段；保留一个真正独立的冻结验证阶段。
4. 删除“用现有 R02/R03 形成最终 P1_PASS”的可能性。

### 建议替代路线

1. **B0R：来源、暴露与适用域审计。** 登记所有 run 已被查看的程度、框来源、条件覆盖、冻结 P0 在各 run/目标位置的局部适用性；不研究新特征结论。
2. **P1E：现有语料探索。** 单帧位置特异性和补偿后时序一致性分轨；人工原生框为主、插值为敏感性；建立匹配背景、空间偏移对照和直接失败病例图谱。
3. **P1-FREEZE：预注册。** 最多冻结两类主测量、代码/输入哈希、效应门槛、覆盖门槛、弃权状态和运行时字段。
4. **P1V：新数据盲验证。** 一次性运行新封存 run，不调参、不删困难条件。通过后才开放 P2；没有新数据则停止在 P1_EXPLORATORY_ONLY_NO_BLIND_CONFIRMATION。
5. **跨模态审计后置。** SAR 证据接口冻结后，再审计光学—SAR时差与方位壳；光学不参与选择正确 SAR 响应。

## 五、最终审阅意见

草案可以作为深化研究的**方向性骨架**，但必须先修正数据暴露、框条件循环、局部误差预算和确认门槛。当前最有价值的下一步不是直接启动 P1C，而是完成 B0R，并把现有四个 run 诚实地当作病例丰富但已暴露的开发语料，形成少量可运行、可证伪、可在任意候选位置计算的 SAR 测量。没有新的盲确认采集前，不建议授予 P1_PASS，也不建议开放 P2。
