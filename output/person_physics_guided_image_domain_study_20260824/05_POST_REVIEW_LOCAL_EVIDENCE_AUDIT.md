## 1. 结论先行

独立审阅提出的主要问题得到本地证据支持：

1. 现有 R01ZF、R02ZF、R03ZF、R04ZF 四个 run 都已经被查看并用于形成过 PERSON 响应或失败类型假设，不能再充当真正未暴露的 P1 确认集。
2. 852 个接受框中只有 251 个是原生人工框，600 个是线性插值框，另有 1 个由插值框人工调整而来。任何依赖框中心、框宽高或平滑轨迹的测量都有框条件循环风险。
3. lag 1、3、5 的人工—人工端点覆盖差异很大。R01/R04 的 lag 5 人工端点对明显多于 lag 1；R03 三个 lag 均没有人工—人工端点对。不同 lag 的差异不能直接写成 PERSON 时序或动力学规律。
4. 398/398 帧的同步状态都是 `NOMINAL_INDEX_FPS_ZERO_OFFSET_UNVERIFIED`；frame 与 optical-person 记录中都没有 behavior 字段。光学行为当前不能作为 P1 核心确认变量。
5. 条件与 run 高度绑定：近邻融合、四人及显示跳变、20 m 外边界、长时序分离目标分别集中在少数 run。当前无法把“条件效应”与“run 特异性”可靠分开。

因此，现有四个 run 的合理角色是：

- 用于 `P1E` 的测量开发、内部稳健性、失败病例和表示敏感性；
- 不用于授予 `P1_PASS`；
- 若没有新的封存独立采集组，最高只能停在 `P1_EXPLORATORY_ONLY_NO_BLIND_CONFIRMATION`；
- P2 继续关闭。

这不改变 P0：`P0_PASS` 仍然成立。P0 证明的是公共表观运动在冻结伪彩图像域协议下达到 PERSON 尺度内的去混杂资格，不是 PERSON 响应已经得到盲验证。

需要区分四种数量：

## 5. 框来源怎样影响 lag 证据

对同一 run、同一 PERSON ID，只有在 `t` 与 `t+lag` 都存在接受框时才形成一个轨迹帧对。下表列出全部轨迹帧对以及“两端都是原生人工框”的数量：

| run | lag 1 人工/全部 | lag 3 人工/全部 | lag 5 人工/全部 |
|---|---:|---:|---:|
| R01ZF | 4 / 361（1.1%） | 20 / 355（5.6%） | 72 / 349（20.6%） |
| R02ZF | 12 / 88（13.6%） | 8 / 80（10.0%） | 8 / 72（11.1%） |
| R03ZF | 0 / 36（0%） | 0 / 34（0%） | 0 / 32（0%） |
| R04ZF | 4 / 356（1.1%） | 37 / 350（10.6%） | 79 / 344（23.0%） |

这张表说明：

1. R01/R04 的 lag 5 更容易碰到人工锚点组合，lag 1 几乎都含插值端点；三种 lag 的标注误差结构不同。
2. R03 的 lag 1/3/5 时序评价全部依赖至少一个插值端点，不能提供人工端点时序确认；R03 更适合作为单帧外边界病例。
3. lag 5 人工对较多不是“lag 5 的物理证据天然更强”，而与人工标注间隔结构有关。R01 的连续人工框间隔中，5 帧间隔出现 49 次；R04 中 5 帧间隔出现 36 次。
4. P0 的 lag 1/3/5 又分别使用 M1、M2、M2，不同 lag 的残差差异还包含模型形式和时间跨度差异，不能直接解释为速度、加速度或动力学。

这个发现不推翻 P0。P0 已按协议同时报告全部接受框和人工端点敏感性，并只检验“公共补偿是否降低残差”。它限制的是下一阶段：不得把跨 lag 差异升级成 PERSON 时序规律，也不得用插值轨迹的平滑性制造时序一致性。

## 7. 同步和光学行为为什么必须后置

字段级核验结果：

- 398/398 帧：`NOMINAL_INDEX_FPS_ZERO_OFFSET_UNVERIFIED`；
- frame 记录中的 behavior 字段：0；
- 694 条 optical-person 记录中的 behavior 字段：0；
- 合同明确写明 `physical_sync_verified=false`。

所以当前能够使用的光学内容仍只能是“未验证同步下的时间/连续性/方位搜索假设”。不能在 P1 中按所谓行为标签分层后宣称 SAR 响应随行为变化，更不能把名义同帧当作物理同步。光学行为与时差应在 SAR 测量接口冻结之后另设审计。

## 8. 现有数据接下来能研究什么

现有四个 run 可以支持两条、且只支持两条主要开发通道：

### 8.1 单帧位置特异性

问题不是“框里亮不亮”，而是：

> 一个可在任意候选位置计算的 SAR 显示域响应分数，在离线 PERSON 参考位置是否高于距离、方位、有效像素和局部结构匹配的背景位置与固定空间偏移位置？

人工框只用于离线判断参考位置；真实框中心、宽高和 `physical_target_id` 不能成为运行时分数的输入。R03 可在这条通道中作为边界不可比较/弃权病例。

### 8.2 补偿后时序一致性

问题是：

> 使用冻结 P0 公共表观运动和目标位置附近的局部误差预算后，任意候选位置的响应支持能否在 lag 1/3/5 上保持位置一致，并优于固定背景或空间偏移对照？

这条通道必须先审计冻结 P0 在 R02/R03 的适用性，并显式携带邻近背景留出残差、锚点覆盖/外推距离、显示变化层和框来源。全场背景中位残差不能直接代替目标位置局部不确定度。

## 9. 现有数据不能回答什么

当前不能据此确认：

- PERSON 存在跨采集稳定的固有 RCS 或固定模板；
- 框轨迹代表人体独立物理运动；
- lag 差异代表速度或动力学；
- 光学行为与 SAR 响应已经物理同步；
- 某个测量已经在真正未见 acquisition group 中复现；
- 现有 R02/R03 可以授予 P1_PASS；
- P2 已具备开放资格。
