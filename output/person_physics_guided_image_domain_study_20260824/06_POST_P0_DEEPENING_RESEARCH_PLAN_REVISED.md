## 1. 总体研究阐述

研究对象始终是目标、场景、载体、成像处理和显示链共同形成的条件性响应，不是人体固有 RCS 模板。

## 2. 为什么必须修改原路线

审阅前草案采用 `B0 → P1A → P1B → P1C`。独立审阅和本地证据审计发现：

- 现有四个 run 已全部暴露；
- 条件与 run 高度混杂；
- 600/852 个接受框来自线性插值；
- lag 与框来源结构混杂；
- 同步未验证且没有 behavior 字段；
- 原方案没有真正未见的确认采集，也没有量化冻结主终点。

因此路线改为：

`B0R 来源/适用域审计 → P1E 现有语料探索 → P1-FREEZE 预注册 → P1V 新采集盲验证 → 再决定是否开放 P2`

其中现有四个 run 只进入 B0R/P1E；P1V 必须使用新封存采集组。

### 4.3 B0R-3：目标位置局部误差预算

时序研究不能只引用“全场背景残差中位数”。对每个候选位置 `x`、帧对 `(t,t+lag)`，应建立局部预算：

\[
\epsilon_{P0}(x,t,\ell)
= f\bigl(r_{bg}^{near},\ d_{anchor}(x),\ coverage(x),\ display\_stratum,\ lag\bigr)
\]

其中：

- `r_bg^near`：目标位置邻近的留出背景锚点残差分布；
- `d_anchor(x)`：候选位置到可靠背景锚点支持区的距离；
- `coverage(x)`：锚点是否从距离和方位两侧包围候选位置，还是仅作外推；
- `display_stratum`：BASELINE/ELEVATED/HIGH，只是显示变化层，不直接解释为增益；
- `lag`：1/3/5，并携带各自冻结模型，不解释为动力学。

预算的计算形式和不可比较阈值必须在 P1E 时序分析前冻结。PERSON 框不得参与公共场拟合或局部预算拟合。

- `P0_COMPENSATION_NOT_COMPARABLE`：只允许单帧病例研究；

## 5. P1E：现有四 run 的探索开发

P1E 只保留两类主测量族，其余形态量都只能作为解释性附属量，避免在大量特征中事后挑成功项。

### 5.1 测量族 A：单帧位置特异性

#### 问题

在任意候选位置都可计算的响应分数，是否在离线 PERSON 参考位置高于匹配背景和固定空间偏移位置？

#### 运行时边界

- 分数输入只能来自 SAR 图像、扇面几何、固定物理/像素尺度库和可用性掩膜；
- 真实接受框中心、宽高、`physical_target_id` 只能用于离线评价，不能用于产生分数；
- 不允许先以真实框裁块，再把“框中心附近最亮”当作定位证据；
- 对照位置只是评价采样点，不是新 SAR 框。

#### 候选定义

先用固定尺度 `s` 定义中心支持区 `C_s(x)` 和外环 `A_s(x)`。对显示域稳健表示 `R_t(p)`，候选位置分数可写为：

\[
S_{loc}(x,s)
= Q_q\{R_t(p):p\in C_s(x)\}
- Q_q\{R_t(p):p\in A_s(x)\}
\]

其中 `R_t` 只允许是预先限定的显示域代理，例如局部梯度/秩或 JET 索引代理；它们仍不是幅度或 RCS。尺度库、分位数 `q`、中心区/外环形状和尺度汇聚规则都只能在 P1E 中开发一次，随后进入 P1-FREEZE。

主比较不是分数绝对值，而是：

\[
\Delta S_{loc}
= S_{loc}(x_{ref})
- median\{S_{loc}(x_{control,k})\}
\]

对照至少包括：

- 同距离、近方位、有效像素匹配的背景位置；
- 固定径向/切向空间偏移位置；
- 局部硬背景位置。

这样检验的是位置特异性，而不是“整幅图这个时刻是否更亮”。

### 5.2 测量族 B：补偿后时序一致性

#### 问题

若候选位置在 `t` 时刻得到响应支持，经冻结公共运动场输运后，`t+lag` 的预测位置是否仍得到局部响应支持，并优于不补偿与空间偏移对照？

预测位置：

\[
\hat x_{t+\ell}=x_t+\hat u_{t,\ell}(x_t)
\]

时序支持只在局部误差预算允许时计算：

\[
S_{temp}
= S_{loc}(\hat x_{t+\ell})
- median\{S_{loc}(\hat x_{t+\ell}+\delta_k)\}
\]

其中固定偏移 `\delta_k` 在 P1-FREEZE 前确定。可增加局部响应峰相对预测位置的距离，但其容差必须由 `epsilon_P0` 与固定尺度库决定，不能用真实目标位移反推。

局部相似度若被使用，只能作为显示重复性的软证据；不得作为身份、人体概率或物理散射稳定性证明。

### 5.3 数据使用规则

- R01/R02/R03/R04 全部标记为 `EXPLORATORY_DEVELOPMENT`；
- 主评价使用原生人工框；
- 插值框只用于覆盖、可视化和敏感性，不作为独立样本扩充；
- R03 的 lag 1/3/5 没有人工—人工端点对，不承担人工端点时序确认；
- 汇总单位优先为 `run × target × time_block`，不把重叠帧对当独立样本；
- 留一 run 检查只能称内部稳健性，不能称盲验证；
- 失败帧、弱响应、融合、边界、显示变化和 P0 不可比较状态原样保留。

## 6. P1-FREEZE：确认前预注册

P1E 完成后，最多冻结两个主终点：单帧位置特异性一个、补偿后时序一致性一个。正式冻结必须包含：

| 冻结项 | 必填内容 |
|---|---|
| 公式 | 输入表示、中心/外环、尺度库、分位数、尺度汇聚 |
| 运行时字段 | 明确哪些字段可在任意候选位置获得，禁止真实框与 ID |
| 主比较 | 参考位置、匹配背景、固定空间偏移和无补偿对照 |
| 效应量 | 逐 target/run/time-block 的差值或比值 |
| 最小有意义效应 | 数值门槛及其业务/几何依据，不能只要求方向为正 |
| 覆盖门槛 | acquisition group、run、target 和时间块层级覆盖率 |
| 弃权 | P0 局部预算不足、边界无效、显示变化或低有效像素状态 |
| 框来源 | 原生人工框主评价，插值只作敏感性 |
| 聚类单位 | 禁止把重叠帧对按独立样本计算 |
| 失败规则 | 不删除困难帧，不允许单一 run/target 驱动通过 |
| 哈希链 | 输入、代码、配置、阈值和预注册文档 SHA256 |

数值门槛在 P1E 结束后、查看任何 P1V 图像和结果前一次性冻结。若最小有意义效应缺少几何或 P2 操作需求依据，不得用开发集最佳分位数随意填充。

## 7. P1V：新封存采集组盲验证

### 7.1 数据要求

- 必须是未用于特征设计、阈值选择、图示选择或失败类型归纳的新 acquisition group；
- 最好至少两个独立采集组；
- 记录场景、采集时段、载体/处理配置、显示链版本和同步状态；
- 单人、多人邻近、显示变化和边界条件应尽量在不止一个采集组出现，避免条件再次与 run 完全绑定；
- 数据在 P1-FREEZE 后封存，盲运行前只允许做输入完整性检查。

### 7.2 一次性验证

- 不调公式、尺度、阈值、P0 模型或弃权规则；
- 不删除困难帧；
- 不用光学或人工 ID 选择正确 SAR 响应；
- 先输出逐 acquisition group / target / time-block 的直接效应，再汇总；
- 同时报告人工主评价、全部接受框敏感性、匹配背景和空间偏移对照；
- 最差病例必须图像复核。

### 7.3 结论状态

- 全部冻结门槛通过：`P1_BLIND_VALIDATED_SAR_RESPONSE_INTERFACE_READY_FOR_P2_REVIEW`；
- 冻结测量在新数据上不复现：`CONDITIONAL_PERSON_RESPONSE_NOT_STABLE_ENOUGH_FOR_P2`；
- 没有新盲数据：`P1_EXPLORATORY_ONLY_NO_BLIND_CONFIRMATION`；
- 输入或适用域不足：`P1V_NOT_EVALUABLE_UNDER_FROZEN_PROTOCOL`。

只有第一种状态才允许讨论 P2；也只是“可以审议”，不是自动启动。

## 8. 光学与 P2 为什么后置

当前 398 帧同步均未验证，且没有 behavior 字段。光学行为不进入 P1 核心。

1. 验证光学—SAR时间偏移/漂移，而不是默认同帧；

3. 光学只限制时间和方位搜索范围；
4. SAR 的位置特异性与时序支持分数决定壳内最终响应位置；
5. 不允许运行时使用人工 `physical_target_id` 选择正确轨迹或亮点。
