二、两个接口必须严格分开

Optical track-shell 接口

  • 输入：自动光学检测/tracklet、固定 optical→SAR 方位映射、固定 guard、预定义时间半窗、SAR 扇面几何；
  • 输出：每条 track 独立的粗 azimuth shell；
  • 禁止：人工 physical_target_id、SAR reference、SAR range GT、人工选“正确 track”；
  • 所有 track 分支均先输出，reference 只在最后离线评价。

SAR response-region 接口

  • 输入：冻结 C2 的实际候选场 S(x)=fixed_support_mean_v2(C2)；
  • 规则：全有效域 q90/q95/q97.5、4096-bin percentile、8-connectivity；
  • 不做：形态学桥接、面积删除、watershed、PERSON 个案调阈值；
  • region 是显示域条件性响应，不是 PERSON 框，也不是人体固有 RCS 或稳定散射中心。

“runtime”准确口径：raw fragment 来源最接近现有运行时可获得的自动 tracklet；但本轮 ±100/250/500 ms 使用居中窗口，可能包含未来光学观测。因此它是带缓冲/离线时间不确定度诊断，不是已经完成的零延迟 causal online tracker。

八、这轮最重要的六个直接回答

Q1 · 现有光学链是否已有可靠 runtime track identity？

还没有

自动 raw fragments 可以作为主运行时近似输入，但 R02 碎片化严重；stitched accepted 是全 run Hungarian stitching 与短缺口插值的 GT-blind offline proxy，不能替代严格 causal runtime identity。

Q2 · 每条 track 独立出壳是否比 all-person union 更有用？

对 P01/P02 有额外搜索压缩

P01 11→3→2，P02 18→6→4；说明 track-conditioned 壳能把全场竞争进一步缩小。但它依赖 tracklet 可用性和重叠，不保证唯一定位。

Q3 · P03/P04 的 optical shells 是否已经分离？

没有稳定分离

当前 guard、时间不确定度、fragment availability 使两壳仍明显重叠；因此 shared SAR region 与 optical identity 的关系还不能被强判定。

Q4 · response-region 是否比 peak node 更忠实？

是，尤其对 response-present / peak-missing

F482/F490 被一致修正为 q95 region present；q95 reference direct coverage 98.0%，固定/几何空间对照显著更低。它更忠实地表达连续 C2 field，但不是 PERSON 框。

Q5 · 它是否解决 shared / 空间未分离？

没有，而且明确保留了 shared 状态

总体 q95 shared 37.5%，R02 94.4%；P03/P04 仍可落在同一 compact region。shared region 只表示图像域重叠，不能直接声称物理散射融合。

Q6 · 接口清楚后，下一步是什么？

先补 runtime track/sync，再做最小 region-shell 时序相交

最有价值的是把 centered diagnostic 变成可量化的 causal/buffered track uncertainty，并验证 track 分支连续性；之后才研究 optical track shell ∩ SAR response region + 冻结 P0 region propagation。本轮没有实现 region tracker，也没有进入 P2。
