## Implementation

The adapter is in `tasks/tpgt_phase_1a/observation_workbench/` and is generated by `enhance_observation_workbench.py`.

- `OBSERVATION_VIEW.html`: default blind view; only source optical overlays and display-domain optical/SAR media are available.
- `OPEN_BOOK_VIEW.html`: deliberate second stage; loads `open_book_registry.json` only after navigation.
- `workbench.js`: native SAR point/rectangle marking, playback, bookmarks, append-only revisions, JSON export/import, contact sheets, and separate interpretation layer.
- `serve_workbench.py`: localhost server with append-only `records/` and `interpretations/` persistence.
- `check_observation_workbench.py`: browser delivery QA, not scientific validation.

## Schema and provenance

- `TPGT_OBSERVATION_RECORD_v0.1.json` is independent of Canonical Schema v1-R1.
- `TPGT_INTERPRETATION_CANDIDATE_v0.1.json` is a separate post-open-book layer.
- `TPGT_IDENTITY_VISIBILITY_ANNOTATION_v0.1.json` reserves a read-only/importable future CAR interface.
- PERSON manual SAR references, interpolated seeds, and historical/proxy metadata remain separate layers with explicit provenance.
- Blind revisions are `PRE_OPEN_BOOK`; later changes create `POST_OPEN_BOOK` revisions and do not overwrite the blind revision.
